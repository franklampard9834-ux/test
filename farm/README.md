# 농장 (Garry's Mod 샌드박스 애드온)

송아지를 사서 키우고, 우유를 짜고, 번식시켜 등급을 개량하는 방치형 농장입니다.
접속을 끊어도 농장 시간은 흐르고, 다시 들어오면 그동안의 일이 계산되어 이어집니다.

## 설치

`farm` 폴더를 `garrysmod/addons/`에 넣고 게임(서버)을 재시작합니다.

## 시작하기

1. 관리자가 스폰 메뉴 → 엔티티 → 농장 → **농장 상점**을 설치합니다. 위치는 맵별로 저장됩니다.
2. 상점(E)에서 송아지, 사료, 사료통을 삽니다. 처음엔 코인 1500으로 시작합니다.
3. 채팅에 `!farm`을 입력해 농장 메뉴를 열고 사료통을 설치합니다.
4. 사료통을 바라보고 E로 사료를 채웁니다. 소는 400유닛 안의 사료통에서 먹습니다.
5. 송아지를 바라보고 E → 우유 먹이기. 우유 1병이 2시간 분량이고, 8시간 먹으면 다 자랍니다.
6. 다 자란 암소는 젖이 차오릅니다(4시간이면 가득). E → 착유하기.
7. 우유와 소고기는 상점에서 팝니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 성장 | 송아지는 먹은 우유가 있는 동안만 자람 (8시간) |
| 사료 | 성체 1마리가 시간당 1 소비, 사료통 최대 120 |
| 우유 | 암소 시간당 1병 × 등급 보너스, 4시간분이 차면 멈춤 |
| 번식 | 전성기 암소 근처(400)에 전성기 수소가 있고 둘 다 배부르면 1시간 뒤 임신, 4시간 뒤 출산, 출산 후 2시간 휴식 |
| 수명 | 5일부터 노년(우유 절반, 번식 불가), 7일에 수명이 다해 소고기 1개가 보관함으로 |
| 출하 | 성체를 E → 출하. 전성기는 소고기 2개, 노년은 1개 |
| 등급 | 1++ / 1+ / 1 / 2 / 3 (상점 송아지는 모두 3등급). 생산 보너스 +40% / +25% / +10% / 0 / 0 |
| 새끼 등급 | 기본 확률 85% + 부모 평균 등급 영향 15% |

- 소와 사료통은 물리건으로 옮길 수 있습니다(주인만). 놓은 곳 근처를 돌아다닙니다.
- 사료통은 Alt+E로 회수합니다. 안의 사료도 돌려받습니다.
- 맵이 바뀌면 소와 사료통은 보관함에 들어갑니다. `!farm`에서 꺼낼 수 있습니다.
- 동물은 굶어 죽지 않습니다. 배고프면 성장과 생산이 멈출 뿐입니다.

## 서버 설정

| ConVar / 명령 | 설명 |
|---|---|
| `farm_timescale 1` | 농장 시간 배속. 테스트할 때 `60`으로 하면 실제 1분이 농장 1시간 |
| `farm_max_cattle 10` | 플레이어당 소 최대 마릿수 (임신 중인 새끼 포함) |
| `farm_givecoins <양> [이름]` | 슈퍼관리자용 코인 지급 |

데이터는 서버 `sv.db`의 `farm_players`, `farm_objects`, `farm_shops` 테이블에 저장됩니다.
가격, 시간, 등급 확률은 `lua/farm/sh_config.lua`에서 바꿀 수 있습니다.
